# 🏡 Flatify

**Find your space. Find your people.**

Flatify is a web-based rental property discovery platform designed to simplify the process of finding flats and compatible flatmates. It connects people searching for accommodation with property owners and individuals looking for shared living arrangements.

## ✨ Core Features

- **Flat Discovery:** Explore rental properties based on location, budget, property type, and amenities.
- **Flatmate Finder:** Discover potential flatmates based on lifestyle, preferences, and budget compatibility.
- **Property Listings:** Allow property owners and existing tenants to publish available flats or vacant rooms.
- **Smart Matching:** Find compatible flatmates through preference-based matching.
- **Saved Listings:** Bookmark interesting properties and flatmate profiles.
- **User Profiles:** Create and manage personal profiles and accommodation preferences.
- **Messaging:** Connect with property owners and potential flatmates.

## 🚀 Getting Started

### Prerequisites
- Node.js (LTS)
- npm
- MongoDB

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Flatify.git
cd Flatify
```

Install frontend dependencies:

```bash
cd frontend
npm install
npm run dev
```

Install backend dependencies:

```bash
cd ../backend
npm install
npm run dev
```

Configure the required environment variables before starting the backend.

## 🎯 Project Objective

The objective of Flatify is to make accommodation discovery more accessible, convenient, and efficient by bringing property listings and flatmate discovery together under one platform.

Instead of navigating multiple platforms and relying on scattered information, users can discover suitable living spaces and connect with people who share compatible accommodation preferences.
